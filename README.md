# 🕯️ Royal Library

**Royal Library** is an elegant, parchment-themed book logging and review application built with Flutter. It allows readers to catalogue their favorite reads, write detailed reviews, save memorable quotes, and automatically pull cover artwork using Open Library integration.

---

## ✨ Key Features

- 📚 **Book Cataloguing:** Add and track books with author, genre, rating, detailed review, and favorite quotes.
- 🎨 **Vintage UI Design:** Custom aesthetic with warm parchment styling, gold rating badges, and card views.
- 🖼️ **Open Library API Integration:** Automatically fetches cover artwork using Open Library Cover IDs (`covers.openlibrary.org`).
- 🔍 **Search & Filter:** Instantly filter book collections by title or author.
- 📱 **Cross-Platform:** Built with Flutter for web deployment and mobile responsiveness.

---

## 🛠️ Tech Stack

- **Framework:** Flutter (Web & Mobile)
- **Language:** Dart
- **External API:** Open Library Covers API
- **Deployment:** GitHub Pages

## 🚀 How to Run Locally

### Prerequisites
- Flutter SDK installed
- Dart SDK
- Chrome browser or mobile emulator

### Steps

1. **Clone the repository:**
   git clone https://github.com/Ddivya11/book_review_flutter_app.git

2. **Navigate to the project folder:**
   cd book_review_flutter_app

3. **Fetch dependencies:**
   flutter pub get

4. **Run the web application:**
   flutter run -d chrome
